# MEMORY — 長期記憶

毎セッションで必ず読まれる、短くて重要な「事実・好み・決定」のリスト。
**長文の調査結果や組織情報は `knowledge/<topic>.md` に書き、ここには書かない**こと（このファイルが肥大化すると毎回トークンを浪費する）。

書き方:
- 1項目1〜3行で簡潔に
- 古くなった項目は更新または削除
- 肥大化したら（200行超）トピックごとに `knowledge/` へ切り出す
